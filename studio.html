Fitur Utama

Semua yang Anda butuhkan untuk studio profesional

Didesain secara presisi untuk pengajar, pembicara seminar, streamer, dan profesional yang membutuhkan performa tinggi tanpa kerumitan teknis.

Dual-Canvas Studio Mode

Tampilan Preview & Program (LIVE) dengan isolasi state penuh layaknya studio siaran TV profesional.

  • Viewport 16:9 Presisi: Rasio kanvas 1920×1080 (60 FPS) standar siaran internasional.
  • Transisi Halus: Tombol transisi instan (Cut) maupun pudar (Fade) dengan durasi fleksibel.
  • Bebas Sunting di Preview: Edit, rotasi, ubah layer tanpa merusak tampilan LIVE yang sedang ditonton pemirsa.

Native Virtual Camera (DirectShow)

Kirim hasil olahan studio langsung sebagai kamera virtual ke seluruh aplikasi rapat & konferensi.

  • Kompatibilitas Luas: Otomatis terdeteksi di Zoom, Microsoft Teams, Google Meet, Discord, Skype, dan WebRTC.
  • Zero-Admin Driver: Pendaftaran driver kamera tingkat pengguna tanpa memerlukan hak Administrator Windows.
  • Shared Memory Ring Buffer: Protokol NV12 1080p @ 30 FPS untuk latensi ultra rendah dan bebas lag.

Beragam Sumber Layer (Rich Sources)

Gabungkan berbagai materi presentasi multimedia dalam satu kanvas terpadu secara fleksibel.

  • Webcam Estetik: Sudut membulat (Rounded Radius) 0–160px dengan bingkai border warna siaran.
  • PowerPoint COM Automation: Navigasi slide presentasi HD langsung dengan remote pointer.
  • Display & Window Capture: Tangkap layar monitor penuh atau jendela aplikasi Windows tertentu.
  • TimeSource & Jam: Jam Real-Time, Stopwatch, dan Countdown dengan efek Digital LED Neon Glow.

Filter & Chroma Key Lanjutan

Hapus background green screen dan manipulasi layer secara instan dengan alat presisi tinggi.

  • Chroma Key & Color Key: Pengaturan similarity, smoothness, dan spill reduction yang bersih.
  • Screen Color Picker: Pipet sampel warna RGB langsung dari area layar manapun dengan floating magnifier.
  • Transform Menu: Rotasi 90°/180°, Flip Horizontal/Vertical, Snap Fit to Screen, dan Picture-in-Picture.
  • Crop Instan: Potong tepi layer langsung di kanvas cukup dengan menahan Alt + Drag.

WASAPI Audio Mixer Terpadu

Kendali penuh suara sistem desktop loopback dan input mikrofon secara simultan tanpa latency.

  • Peak Level Meter Responsif: Indikator dB visual real-time dengan tanda kliping distorsi.
  • Kontrol Mute & Slider Gain: Sesuaikan desibel volume tiap channel audio dengan satu klik.
  • Sinkronisasi Video: Playback audio video otomatis tersinkron saat beralih ke Program LIVE.

Fullscreen Projector & Auto Updater

Dukungan presentasi proyektor panggung dan pembaruan aplikasi otomatis yang praktis.

  • Projector Layar Kedua: Lempar kanvas ke proyektor eksternal secara instan (keluar cukup tekan Esc).
  • Auto Updater Terintegrasi: Mendeteksi rilis rilis terbaru GitHub dan update mandiri tanpa install ulang.
  • Manajemen Scene Thumbnail: Tampilan Scene dalam mode Grid 16:9 real-time yang memanjakan mata.

Pintasan Keyboard

Bekerja lebih cepat dengan Hotkeys Ringkas

Seluruh pintasan penting dirancang ergonomis agar Anda dapat mengendalikan siaran tanpa kehilangan fokus.

Pintasan Tombol Aksi / Fungsi
Ctrl + F Fit to Screen: Sesuaikan ukuran layer terpilih persis memenuhi kanvas dengan menjaga aspek rasio.
Ctrl + S Stretch to Screen: Rentangkan layer terpilih hingga memenuhi seluruh sudut layar kanvas.
Ctrl + D Center to Screen: Posisikan layer terpilih tepat di titik tengah kanvas studio.
Ctrl + R Reset Transform: Kembalikan ukuran, rotasi, dan posisi layer ke nilai standar awal.
Ctrl + C Copy Source: Salin layer beserta seluruh konfigurasi filter, border, dan ukurannya.
Ctrl + V Paste Source: Tempelkan konfigurasi layer yang disalin ke scene yang aktif saat ini.
Alt + Drag Edge Direct Crop: Potong tepi sisi layer secara langsung di area Preview kanvas.
Esc Escape: Tutup tampilan Fullscreen Projector atau batalkan operasi Color Picker.

Panduan Penggunaan

Instalasi & Menjalankan Aplikasi

Cara 1: Binary Executable (Rekomendasi)

Sangat mudah, portabel, dan langsung jalan tanpa perlu instalasi rumit:

  1. Buka tab GitHub Releases dan unduh file nexora-studio.exe.
  2. Simpan file di folder pilihan Anda (misal Desktop atau Program Files).
  3. Klik dua kali untuk menjalankan langsung!

Cara 2: Kompilasi dari Source Code

Jika Anda seorang developer Rust dan ingin mengkompilasi sendiri:

PowerShell Cargo Toolchain 
# 1. Clone repository
git clone https://github.com/nexora-ctrl/nexora-studio.git
cd nexora-studio

# 2. Build rilis optimal
cargo build --release
