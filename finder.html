Fitur Utama

Kecepatan tanpa kompromi, desain tanpa cela

Semua fitur dirancang khusus untuk memangkas waktu Anda mencari berkas di Windows tanpa harus menunggu indexing berat bawaan OS.

Pencarian Super Instan (< 1 ms)

Mencari di antara jutaan berkas tanpa jeda menggunakan sistem pengindeksan canggih berkecepatan tinggi.

  • Indeks Kilat Real-Time: Struktur indeks terbalik yang sangat optimal dan instan.
  • Penyimpanan Metadata Terpadu: Manajemen riwayat dan penelusuran berkas yang tertata rapi.
  • Zero Lag: Hasil pencarian muncul seketika saat karakter pertama diketikkan.

Jendela Spotlight Adaptif

Antarmuka mengambang di tengah layar yang secara otomatis menyesuaikan ukuran jendela sesuai kebutuhan.

  • Ramping Saat Standby: Hanya menampilkan bilah pencarian elegan saat baru dibuka.
  • Melebar Dinamis: Animasi ekspansi halus ke bawah segera setelah hasil ditemukan.
  • Efek Glassmorphism: Latar kaca frosted transparan dengan aksen gradient modern.

Filter Kategori & Drive Cepat

Pilah dan persempit pencarian secara instan berdasarkan tipe file dan partisi drive Windows Anda.

  • 8 Kategori Bawaan: Folder, Dokumen, Gambar, Video, Audio, Aplikasi, Arsip, dan Kode.
  • Filter Drive Mandiri: Cari di seluruh drive (All) atau isolasi drive tertentu (C:, D:, dll).
  • Pintasan Tab: Beralih filter kategori dengan cepat menggunakan tombol Tab.

Menu Klik Kanan Kustom (Context Menu)

Integrasi langsung ke Windows Explorer untuk tindakan berkas yang paling sering dibutuhkan.

  • Buka: Jalankan berkas dengan program default Windows.
  • Buka dengan... (Open with): Dialog resmi Windows untuk memilih aplikasi pembuka.
  • Buka lokasi berkas: Buka File Explorer dan langsung menyorot posisi file tersebut.
  • Salin Jalur: Menyalin path absolut direktori ke clipboard secara instan.

Auto Minimize Cerdas

Aplikasi tidak pernah menghalangi alur kerja Anda dan otomatis bersembunyi saat selesai.

  • Auto-Hide saat Enter: Menekan Enter langsung membuka file dan meminimalkan Finder.
  • Klik di Luar Jendela: Mengklik area layar lain langsung menyembunyikan jendela ke background tray.
  • Konsumsi Memori Rendah: Arsitektur hemat daya memastikan penggunaan RAM dan CPU sangat minim saat standby.

Pintasan Global & Navigasi Penuh

Panggil jendela pencarian kapan saja dari aplikasi mana pun tanpa menyentuh mouse.

  • Panggilan Global: Tekan Ctrl + Alt + S atau Alt + Space dari mana saja.
  • Navigasi Keyboard Lengkap: Panah Atas/Bawah, Enter, Shift+Enter, dan Esc.
  • Mode Terang & Gelap: Mendukung transisi tema mulus yang serasi dengan preferensi OS Anda.

Unduh & Instalasi

Mulai Menggunakan Nexora Finder

1. Versi Rilis Windows

Dapatkan installer resmi siap pakai langsung untuk Windows 10/11 64-bit:

Unduh Windows

Tersedia paket setup installer NSIS lengkap dengan dukungan auto-updater.

2. Mode Pengembangan (Dev Mode)

Jalankan live-reload aplikasi secara lokal untuk pengujian dan kustomisasi:

Terminal / PowerShell Dev Environment 
# Clone repositori
git clone https://github.com/nexora-ctrl/nexora-finder.git
cd nexora-finder

# Pasang & jalankan dev
npm install && npm run tauri dev

3. Membangun Biner Sendiri

Kompilasi file binary executable mandiri langsung dari source code:

PowerShell Production Build 
# Build binary standalone .exe
npm run tauri build -- --no-bundle

Executable portabel akan dihasilkan di folder rilis target Rust/Tauri.
